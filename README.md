# Enemy Invasion - Unity 3D Game Project

### 📝 Project Overview
"Enemy Invasion" is a 3D arcade-style space shooter developed in the **Unity Engine**. The project focuses on integrating 3D graphics with core game mechanics, featuring a wave-based enemy system and real-time interaction.

### 🎮 Gameplay Mechanics
* **Player Control:** A 3D spaceship (cone primitive) with smooth horizontal movement.
* **Combat System:** Real-time projectile spawning (shooting mechanism) to destroy incoming enemies.
* **Enemy AI:** Procedural movement for enemy waves, moving towards the player.
* **Collision Detection:** Advanced physics-based collision handling between projectiles and enemies.
* **VFX:** Particle systems implemented for explosions upon enemy destruction.
* **Game Logic:** Includes "Game Over" states and real-time console debugging for hit tracking.

### 🎨 Graphics & Technical Features
* **Engine:** Unity 2021.3+
* **Environment:** 3D scene with dynamic lighting and shadow mapping.
* **Scripting:** Clean and modular **C# scripts** for player movement, projectile physics, and enemy behavior.
* **Prefabs:** Efficient use of Unity Prefabs for projectiles and enemy units.

### 🛠 Tools Used
* **Unity Engine**
* **C# / Visual Studio**
* **Unity Physics & Particle System**
